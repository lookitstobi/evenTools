So nutzt du den PDF Template Builder

  1. Lade oben eine bestehende Vorlage oder starte mit Neu eine leere.
  2. Per Rechtsklick auf der Vorschau öffnest du das Aktionsmenü mit Hinzufügen, Entfernen, Binding und Raster Lock.
  3. Wähle ein Element an und bearbeite rechts seine Eigenschaften.
  4. Raster-Snap wird bei Bedarf pro Element über Am Raster einrasten aktiviert.
  5. Die Tool-Zuordnung bestimmt die verfügbaren Datenfelder (Bindings).
  6. Mit Speichern wird Titel, Status und Inhalt gespeichert – unabhängig von der Zuordnung.
  7. Mit PDF Vorschau siehst du das serverseitig gerenderte Ergebnis mit Beispieldaten.
